# Measure

Observe how much reading, searching, prompting, source inspection, and manual reconstruction is needed before the founder-maintainer can explain the product and safely scope a change.

The initial assessment is qualitative. Repeated experience should be clearly better than asking a coding agent to reconstruct the product from repository artifacts and scattered external sources.

# Interpretation

A faster answer is not successful if it is based on stale or falsely authoritative knowledge. Confidence must be supported by visible current context and visible uncertainty or disagreement.

# Baseline

No measured baseline or numeric target exists yet. The initial experiment will compare anecdotal experience across multiple owned products.
