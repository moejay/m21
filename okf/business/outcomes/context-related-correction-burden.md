# Measure

Observe changes that must be corrected or discarded because an already-known goal, rationale, or constraint was missed when the work was performed. A representative example would be a feature implemented incorrectly because a relevant accepted constraint was unavailable.

# Exclusions

Do not count deliberate experimentation, newly discovered information, changed goals, ordinary defect correction unrelated to missing context, or valid iteration as avoidable context-related rework.

# Baseline and threshold

No numeric baseline is accepted. The founder-maintainer will continue only when repeated use across multiple products feels materially better rather than marginally better or worse than the current approach.
