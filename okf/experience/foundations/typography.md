# Typography

M21 uses **Manrope** for interface language and **DM Mono** for identifiers, relationship semantics, token names, and compact technical metadata.

## Hierarchy

- Display headings are confident, compact, and sentence-cased.
- Section headings establish rhythm without turning the workspace into a presentation.
- Body copy favors comfortable reading over maximum density.
- Labels and identifiers use monospace sparingly; they orient rather than dominate.

## Principles

1. Preserve legibility at compact workspace sizes.
2. Use weight and spacing before adding color.
3. Keep line lengths bounded in full documents.
4. Never use monospace as decoration for ordinary prose.
5. Respect user font scaling and avoid fixed-height text containers.
