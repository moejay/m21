# Flow

1. The user searches, filters, traverses, or directly opens a concept.
2. M21 enters focus mode and presents the concept's meaningful neighborhood.
3. The user edits directly or asks the agent to develop, challenge, or connect it.
4. Proposed mutations show affected concepts and applicable constraints.
5. Accepted changes update the graph without forcing unrelated upstream revisions.

# Success

The user can make a useful local change while understanding its wider consequences and unresolved assumptions.
