# M21 Agent Skill

The canonical cross-agent skill is [`m21-product-engineering`](m21-product-engineering/SKILL.md). It follows the open Agent Skills directory format and bundles progressive references for M21 spec/feature authoring, project workflow, OKF modeling, and every Definition Area. The skill distinguishes concern-level M21 implementation specs from Definition Area knowledge instead of generating one generic spec per area.

Install it from this repository with the [skills CLI](https://github.com/vercel-labs/skills):

```bash
npx skills add https://github.com/moejay/m21 --skill m21-product-engineering
```

List without installing:

```bash
npx skills add https://github.com/moejay/m21 --list
```

Use directly from a local checkout:

```bash
npx skills use ./skills/m21-product-engineering
```

Agent-specific install locations are generated by the CLI. Do not maintain a second source copy under `.agents/`, `.claude/`, or another harness directory.
